# Ryder Sun Personal Website

Ryder Sun 的个人作品集网站，用于展示 AI 产品经理方向的经历、项目案例与产品判断能力。网站内容围绕 Agent 系统、MCP 工具、ChatBI、信息引擎、招聘 Agent 与科研算法产品化等方向展开。

## 内容结构

- 首页：姓名、职位、动态介绍、个人简介与联系方式
- About：AI 产品能力、Agent 工作流、业务执行链路与个人定位
- Projects：精选项目与案例说明，包含信息平台、MCP 工具、招聘 Agent、ChatBI 与科研算法项目
- Contact：联系方式与社交入口
- Legal / Privacy：个人网站的法律声明与隐私说明

## 技术栈

- Vue 3 + TypeScript + Vite
- GSAP + Lenis 动效
- three.js / WebGL 场景
- Howler 音频
- SCSS 样式系统

## 本地运行

```bash
npm install
npm run dev
```

默认开发服务器端口为 `3000`。

## 验证

```bash
npm run typecheck
npm run build
```
